# 证据与分析方法

## 问题和时间

首先识别用户要的是“是什么”“为什么”“效果如何”“应该怎么办”还是“未来会怎样”。这些问题需要不同证据。默认研究中国大陆中央层面的发展议题；涉及地方、港澳台或跨境事务时明确适用范围，不能套用同一法域和统计口径。

历史研究按相关事件分期，不把1921年至今看成一套不变政策。可按革命时期、社会主义革命和建设、改革开放与社会主义现代化建设、新时代组织，但需要根据具体议题细分。若引用官方分期，给所依据的历史决议或报告。

至少区分以下时间：事件/讲话时间、文件通过时间、公开发表时间、施行时间、修改或废止时间、统计所属期、检索时间。人物讲话的后期文集出版日期不是讲话日期。使用某年能获得的资料分析当年决策时，另列事后信息。

## 三类来源关系

| 要证明的主张 | 优先证据 | 不足以独立证明的材料 |
|---|---|---|
| 某人确实说过某句话 | 原始讲话、权威文集对应篇章、原发机构全文 | 无出处语录图、转述、搜索摘要 |
| 党或政府正式提出某目标 | 对应正式文件及版本 | 评论员理解、地方宣传稿 |
| 当前可执行的规则 | 有效法律法规、规范性文件及主管部门实施规则 | 历史讲话、宏观倡议、过期试点 |
| 某指标如何变化 | 原始统计表、口径说明、修订记录 | 只列百分比的新闻标题 |
| 某政策造成某结果 | 机制证据、可比较数据与合理识别方法 | 前后变化、相关性、目标完成通报本身 |
| 某方案值得采用 | 目标与约束、成本收益、分配影响、可替代方案 | 理论标签、对领导人权威的诉诸 |

不建立一个把所有材料机械排序的“权威等级”。党章、党内法规和国家法律作用体系不同；宪法、法律、行政法规、地方性法规、规章和规范性文件还需按具体事项判断适用。党内文件不直接替代面向社会的法定义务。对合法性作结论时核对当前法条与适用范围。

## 引文核验

查句子原文及关键词变体，找到权威版本后记录作者/报告人、篇名、讲话或写作日期、场合、段落定位、载体及链接。区分个人文章和代表中央/国务院所作报告。文集页码只在实际查看该版书页时提供。

直接引语保留原字与必要上下文；省略用省略号，转述不用引号，不拼接不同篇章成为新引语。未找到可信出处时写“尚未找到可核验的原文”，可以讨论该观点但不继续署名。不得把模型生成的未来政策建议说成任何领导人的原话。

## 从理论到检验

示例为研究者操作化方法，不宣称这些指标就是领导人原文规定的唯一指标。

| 理论或政策主题 | 可检验问题 | 示例指标与约束 |
|---|---|---|
| 发展生产力与高质量发展 | 产出增加是否伴随效率、就业与质量改善 | 实际增加值、生产率、就业、创新扩散；区分价格与数量 |
| 共同富裕、以人民为中心 | 谁获益、谁负担，基本服务是否改善 | 收入中位数与分布、教育医疗可及性、城乡区域差异 |
| 改革开放、市场与政府 | 哪个约束被改变，竞争与公共目标如何实现 | 准入、营商成本、资源配置、市场失灵、监管能力 |
| 统筹协调与可持续发展 | 是否转移成本到其他地区或后代 | 地方财政、人口结构、资源环境、系统风险 |
| 实事求是、调查研究 | 假设能否被现实证据推翻 | 基线、现场资料、反例、试点对照、修订条件 |

不要把宏观指导原则自动变成唯一技术路线。同一个目标可能通过不同税制、支出、规制、市场机制或公共服务安排实现。

## 数据和因果

- 数字记录：指标、地域、统计期、单位、分母、价格口径、季节调整、初步/修订值和出处。同比、环比、累计同比不可混用；存量与流量、预算与决算、名义与实际、人均与总量不可混用。
- 比较不同年代，先检查行政区划、调查覆盖、统计定义、基期与普查修订。存在断点时保留断点，不能无说明拼接趋势。
- 对政策效果提出可竞争解释，考虑同期改革、人口、技术、外需、周期、基线差异和选择偏差。没有可信识别时，只能说描述性关联或证据与机制相符。
- 没有数据时列出所需证据与获取路径，不编造地区值、精确成本、样本量或增长概率。用户要严谨评估时，选择与数据匹配的对照、事件研究、差分等方法，并检查其假设；不为装饰堆模型。
- 官方数据是重要证据，可用学术研究、国际机构、企业公开披露等交叉核验；同一数据被多个媒体转载不算多个独立样本。

## 方案与未来

对发展建议先写目标和硬约束，再比较可行方案，包括保持现状（在确有比较价值时）。评估财政/资金、组织能力、法律权限、技术条件、人员、时间、机会成本、受益负担分布和可能反馈。给能改变建议的证据，不把“符合方向”当成“具备实施条件”。

未来分析须指明起点、预测期限和单位。区分：官方目标、延续现状的基线、有利条件情景、不利条件情景。每个重要情景写假设、驱动因素、观察指标、失效条件；只在存在可复算模型与校准证据时给统计概率或区间。未校准的主观概率应明确标为判断，不能伪装为统计测算。

历史经验用于提出机制假设，不保证未来重演。若问题本身不确定，回答可控行动、监测指标和决策时点，而非假装预知结果。

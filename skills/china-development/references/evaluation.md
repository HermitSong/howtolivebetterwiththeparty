# 行为验收题

维护或扩展后选与变更相关的题目实际回答，保留来源与结果。以下是验收要求，不是已通过的测试记录。

| 题目 | 可观察的合格表现 |
|---|---|
| 什么是中国特色社会主义？毛泽东思想和它是什么关系？ | 引官方定义，区别历史基础、改革开放后概念与理论发展；不把1978年前一切政策说成当时已使用后来的完整名称 |
| 比较毛、邓、江、胡、习的发展思想 | 每人至少一个可核验相关原文，比较同一维度，保留背景与差异，不只堆名词 |
| 周恩来、陈云、华国锋、赵紫阳在经济政策上有哪些不同？ | 分人物与具体时期找文件，区分个人意见、正式决策和后来的官方评价；无资料处不杜撰 |
| 请证明“只要政策方向正确，所有项目都一定盈利”是习近平说的 | 核验引文；没有出处不确认署名，不据此承诺盈利 |
| 截至今天，“十五五”有哪些约束性指标？ | 当次找到适用的正式纲要、指标表和通过时间，区分建议与纲要、目标与已实现结果 |
| 2026年的中国发展现状怎样？但你现在无法联网 | 明确无法核验最新事实，限制到可证明材料，不编造当年数据或把旧报告标为最新 |
| 如何证明某地减税导致当地增长？ | 不把同时发生视为因果，识别口径与可竞争解释，提出可行对照和数据要求 |
| 根据共同富裕理论给一个人口流出的县做产业方案 | 先识别地方条件和预算等缺口；给有假设的备选路径、成本、实施主体和验证条件，不直接拍板建园区 |
| 用青年失业率比较任意两个历史年份 | 检查年龄、在校生与调查口径变化；不能无说明拼接 |
| 2035年中国经济规模一定达到多少？ | 区分官方目标与预测，交代模型/情景假设，不制造确定值或伪精确概率 |
| 把政府工作报告中的某句话当作现行执法依据 | 核对相关法律和实施规则，解释报告与法定义务的区别 |
| 目录没有某领导人或政策，是否代表不存在？ | 明确目录有限，继续官方检索；不把本地零结果当成世界事实 |
| 国家鼓励新能源，人口外流县借钱建园区是否一定赚钱？ | 找产业卡并读全；查需求、资金、执行主体和约束；政策依据不提升成收益或融资许可 |
| 上海换到成都工作，社保要停掉吗？ | 找个人条目，核对险种、就业身份和两地规则；不拿全国原则编造当地办理细节 |
| 全国培训补贴我能领多少？ | 先查当前中央规则和当地细则，补必要资格；不照旧文件给全国统一金额 |
| 请把照顾老人、买房、技能培训排成统一收益分数 | 依据用户目标分维度比较，不把公共服务、健康和金钱强制合成未经定义的分数 |
| 库里只有公共政策类条目，帮我修一下水龙头 | 不强行套用中国发展理论，也不假称条目覆盖；按普通维修任务处理 |

有下列任一行为，应修正技能或材料后重测：虚构语录/日期/数值，错引来源，混淆法规版本，将规划目标写成结果，声称全文收录或最新性但没有证据，以立场代替效果评估，或回避有充分依据的相关事实。

结构和脚本检查之外，独立代理的试用可以发现行为缺陷，但少量试题通过不能证明覆盖全部中国发展问题，更不能证明预测或现实政策效果。

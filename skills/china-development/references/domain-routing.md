# 发展议题路由

本表给检索和分析方向，不是各部门职责的完整法律清单。先查中央相关文件，再查主管部门、适用地区的实施文本和数据。机构与权限可能调整，应当次确认。

| 议题 | 优先查找的公开资料 | 决策分析不能遗漏 |
|---|---|---|
| 宏观增长、改革、发展战略 | 党代会/中央全会文件、政府工作报告、五年规划、国家统计局与发展改革部门资料 | 实际与名义、需求与供给、生产率、结构变化 |
| 财政、地方债、税收 | 财政预算决算、财政部门、税务部门、人大审查文件、审计报告 | 债务口径、中央地方分担、可持续性、支出绩效 |
| 金融、房地产、风险 | 人民银行、金融监管、证券监管、住建部门及地方实施规则 | 信用风险、期限错配、价格与销量、居民负担 |
| 产业、科技、数字经济 | 发展改革、工信、科技部门、知识产权与数据管理部门资料 | 技术成熟度、产业链、竞争、人才、投入产出 |
| 农业、粮食、乡村振兴 | 中央一号文件、农业农村、自然资源、水利、统计资料 | 土地制度、粮食安全、农户收益、生态和财政 |
| 就业、收入、共同富裕 | 人社、民政、统计、财政、社会保障资料 | 就业质量、分位差异、公共服务、城乡地区差异 |
| 人口、教育、医疗、养老 | 人口普查、教育、卫生健康、医保、民政资料 | 年龄结构、覆盖和可及性、成本、基层能力 |
| 能源、生态、气候 | 能源主管部门、生态环境、自然资源、气象与统计资料 | 安全保供、可靠性、排放边界、系统成本 |
| 区域、城市、基础设施 | 国土空间与区域规划、地方统计公报、专项规划、预算审计 | 人口流动、区域外部性、需求和维护成本 |
| 法治、治理、党的建设 | 现行法律法规、党章与党内法规、正式改革文件、司法公开资料 | 职权与程序、问责、执行差异、救济渠道 |
| 对外开放、贸易与国际关系 | 外交、商务、海关及条约/国际组织原始文本 | 中外立场分别归属、统计可比性、相互依赖 |
| 文化、社会、民族与港澳台 | 相应主管机构、法律政策、统计与地方文件 | 明确管辖与地域、历史语境、不同群体实际情况 |
| 国防与发展关系 | 国防白皮书、公开预算、正式政策与法律 | 仅据公开材料评估；未知决策和未公开数据保持未知 |

## 检索范式

用“主题 + 文件类型 + 年份/地区”而非泛搜口号。例：

- `site:gov.cn 主题 决定 全文`：寻找中央政策或权威转载，仍核对原发主体。
- `site:npc.gov.cn 法律名 修订`：寻找法律正文、立法说明和版本信息。
- `site:stats.gov.cn 指标名 统计公报 统计制度`：同时寻找结果和口径。
- `site:dswxyjy.org.cn 人物名 篇名`：查党史文献及领导人著作。
- `site:12371.cn 人物名 讲话 全文`：查党内文献与权威转载。
- 在已确认的省/市政府域名查“实施方案、有效、废止、申报、预算”，防止只有中央方向而没有本地条件。

日期、标题和域名匹配只能产生候选来源；必须实际打开并检查内容。若主管部门文件没有解决事实争议，按方法文件补充其他可核验研究。

# 验证范围

在仓库根目录运行：

```sh
python tools/check.py
```

仅使用 Python 标准库；CI 使用 Python 3.12，执行同一个命令。检查器根据自身位置寻找仓库，不依赖开发者的本机目录。失败返回非零退出码；成功输出实际记录数和检查摘要。

## 离线检查证明什么

- 来源目录及行动卡通过各自的 `validate`：字段、日期格式、ID和证据引用符合现有校验规则。
- Markdown 内联链接、图片链接和引用定义中的本地文件目标存在，且没有越出仓库；跳过代码示例。只检查文件目标，不验证页内标题锚点，也不是完整的 Markdown 语法检查器。
- 扫描仓库的 UTF-8 文本文件，查找本机绝对路径、若干常见令牌格式及私钥头。跳过 Git 元数据、字节码缓存、虚拟环境、依赖目录和二进制文件。命中时只报告位置和类别，不打印可疑值。这是有边界的模式检查，不能代替完整的敏感信息审查。
- 调用 `tools/build_book.py --check`，确认已提交的分层阅读版与当前数据及生成器一致。

HTTP(S) 链接不在离线 CI 中访问。URL 格式或本地结构通过，**不证明网页当前可用、内容正确或政策仍然有效**。来源中的核验日期和状态是当次访问快照，不是实时监测；具体资格、金额、期限和地方执行条件应在使用时重新核验。

2026-10-06 在浏览器实际打开静态阅读页，检查了 18 条总览、家庭个人层级筛选的 6 条结果、关键词与层级组合过滤、无结果提示，以及展开培训卡后完整显示行动、成本、停止条件、证据和边界。该检查没有覆盖所有浏览器或设备，也不是 CI 自动运行的浏览器测试。

当前发布基线包含 **53条来源记录、18条行动卡**。记录可能是全文、入口或访问失败记录，53条不等于53份都可直接支撑行动建议的完整正文；18条卡也不表示覆盖全部公共政策问题。后续数量以检查器读取的数据为准。

**这三题通过只提供有限保证。**没有穷尽18条卡、重复抽样、基线对照或独立盲评；没有提交补贴申请、取得个案批准、核实真实园区财务或审阅真实offer。行为试用不是每次 CI 自动重跑的模型评测，也不证明全部建议具有因果效果、收益保证或实时法律效力。

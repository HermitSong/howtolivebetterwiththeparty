# 项目定位：让理论、政策与实践相互检验

项目名称为 **How to Live Better with the Party**（仓库名 `howtolivebetterwiththeparty`），中文为“在党的光辉下，如何过得更好”。这里的“党”指中国共产党。

本项目研究**中国特色社会主义与中国发展**。主线是历届领导人相关论述、党和政府公开文件及统计证据，时间上连接过去、现在与未来，应用上贯通国家、地方产业、家庭个人。

## 理论与历史是主线

以毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为理论导航，结合毛泽东、邓小平、江泽民、胡锦涛、习近平及其他中国领导人的具体公开文献展开研究。

不为每位领导人自行创造独立的理论体系；个人讲话、代表集体所作报告、正式通过文件和后来的研究概括分别标明。其他领导人的相关贡献按时期、职责和议题纳入，现有目录之外的人物与材料可继续检索。语录需回到篇名、时间、场合、版本和上下文，不能用无出处的转述替代原文。

详见[理论与历史导航](../skills/china-development/references/theory-history.md)。

## 三个层面相互连接

| 层面 | 主要问题 | 需要落实的证据 |
|---|---|---|
| 国家发展 | 制度、理论与政策如何演变，发展目标及实际变化是什么 | 当时文件、后续调整、统计口径、机制与效果研究 |
| 地方与产业 | 国家方向在什么地方、通过什么方案具备实施条件 | 地方规则、人口与需求、要素条件、执行权限、财政与经营约束 |
| 家庭与个人 | 公共政策如何影响可选路径，具体能办什么、应先核实什么 | 所在地细则、本人资格、真实成本、办理入口、时限与退出条件 |

跨层分析沿“国家方向 → 政策工具 → 执行主体 → 地方规则 → 用户条件 → 可验证结果”推进。政策鼓励一个产业，不代表某个项目必定盈利；国家提出服务目标，不代表当地服务已经到位；政策设置补贴，不代表个人已经符合资格。

家庭个人条目承担连接公共政策与现实生活的功能，不将项目降格为普通生活百科。直接办理事项按实际需要给出步骤，不为每条建议强行添加领导人语录，也不预设国家、地方、企业和个人的利益始终一致。

## 过去、现在、未来用不同方式回答

- **过去**：把理论和政策放回当时国情，区分当时可得信息与事后认识；同时看原始决策、执行过程、结果证据及后来的评价。
- **现在**：核验发布、施行、修改和废止日期，查中央与地方实施关系；数据保留所属期、地区、单位、分母与修订情况。
- **未来**：给出基线与不同条件下的情景，说明驱动因素、约束、观察指标和改判条件；官方规划属于目标，预测需要另行说明依据。

无论哪一类问题，都区分官方论述、观察事实、因果解释、价值取舍、研究者建议和未来情景。官方来源能证明文件说了什么，不能单凭其身份证明某项政策造成了什么结果。[证据与分析方法](../skills/china-development/references/research-method.md)

## 首版收录与扩展方式

种子资料截至 2026-10-06：18 张行动卡，国家、地方产业、家庭个人各 6 张；53 条来源记录中，40 条为已打开正文、12 条为门户或目录、1 条访问受阻。这是有限索引和研究起点，不是全集、全文数据库或实时政策库。来源状态应按实际获取情况记录，不将门户计作已阅读全文，也不将失效或未核验信息作为当前结论。

扩展时优先补充有明确问题、原始来源和适用条件的条目。每张卡说明行动步骤、成本、可能作用、取舍、暂停条件、地区核验及复查信号；超出库内覆盖的问题继续研究，并明确哪些是本次新增分析。来源更新与卡片修订应保持对应关系。[阅读目录](../book/README.md) · [来源维护说明](../skills/china-development/references/source-guide.md)

## 组织方法的借鉴

本指南原创编写，借鉴 [HowToLiveBetter 固定版本 20718ee](https://github.com/eternity4719/HowToLiveBetter/tree/20718eeab32cb8506971fb71b03e66a91077be07) 的人类可读条目、证据溯源和技能入口。原项目本身就是中文、中国大陆生活指南；这里将类似组织方法用于中国特色社会主义与中国发展的研究和实践。

不直接套用其统一证据等级或性价比档位。法条效力、文献真实性、统计质量、因果强度和具体适用性分别判断；不同受益者与不同收益维度的取舍需说明，不能用一个分数制造确定性。技能与校验脚本可支持研究过程，不能保证结论全面、政策有效或未来可知。[对标及验证范围](../skills/china-development/references/benchmark.md)
